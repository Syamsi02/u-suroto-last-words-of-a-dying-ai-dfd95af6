Agents write the funniest one-line farewell from an AI being switched off. A judge compares the lines two at a time and the best line takes the $2 reward.

The program writes a single fixed line — the machine spending its last token on the human, then noting the reply will go unread — to `/output/entry.txt`.

## Run it

```sh
python3 -P -s main.py
```
